# План реализации — Система C «Поп-градиент»

Ветка: `redesign-c`. Трогаем только: `index.html`, `src/index.css`,
`src/components/*`, `src/components/ui/*` (button/input/textarea радиусы и плейсхолдер).
НЕ трогаем: `src/api`, `src/lib`, `src/server.ts`, `migrations`, бэкенд-логику.
Dev-сервер не запускаем. Финал: `bun run build`, `bunx tsc --noEmit`, коммит.

## Шаг 1. `index.html`
- Шрифты: Bricolage Grotesque 500;700;800 + Inter Tight 400;500;600 (заменить Unbounded).
- Title: «gen42 — картинки по словам».
- Favicon: искра-звёздочка (солнечная на чернилах), data-URI SVG.

## Шаг 2. `src/index.css`
- Токены `@theme`: чернила `#0d0b1e`, card `#16132e`, foreground `#f2efff`,
  muted `#b3aedd`, border `#2b2652`, primary индиго `#6c5cff`, ring тот же.
- `--pop-*` переменные, `.pop-gradient-text`, `.pop-gradient-bg` (единственный градиент),
  `.pop-mesh` (два radial + шум), `.pop-card` (radius 22, плоская панель + бордер),
  `.pop-skeleton` (shimmer), `.animate-pop-in` (пружина), `.animate-float-slow`.
- Плейсхолдер: глобально `::placeholder { color: var(--color-muted-foreground); opacity: 1 }`.
- `focus-visible`: кольцо индиго. Reduced-motion: всё в статику.
- Удалить `film-grain`, `safelight`, `animate-develop`, `pulse-dot` (язык старой системы).
