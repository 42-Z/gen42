### Паттерны индустрии (Midjourney, Krea, Leonardo, Ideogram, Recraft)

1. Горизонтальный prompt-бар сверху, результат/лента снизу без смены контекста.
2. Настройки (формат, модель, сила AI) — компактные контролы рядом с промптом
   или в боковой панели, центр остаётся чистым.
3. Галерея-история: бесконечная лента/masonry с авто-подгрузкой.
4. Баланс кредитов в правом верхнем углу рядом с профилем.
5. Ограниченная палитра: один акцент на нейтральной базе.

### Обязательные исправления во всех вариантах

Все 5 веток чинят проблемы №5 (роутинг по хешу), №6 (disabled при 0 кредитов),
№7 (стрелки в лайтбоксе), №13 (focus-visible + aria-current), №14 (контраст
плейсхолдера), №19-21 (единая система радиусов/загрузок), №26 (предупреждение
лимита), №27 (примеры-чипы промптов). Различаются визуальные системы.

## Design 1 — «Фотолаборатория 2.0» (эволюция)

**Read:** редизайн-сохранение для внутреннего инструмента, тёмная тёплая тема,
эволюция текущей идентичности. Диски: variance 5, motion 5, density 4.

- Тема: тёмная тёплая (текущая палитра сохраняется), Unbounded + Inter Tight.
- Акцент-дисциплина: янтарь только CTA, прогресс, фокус. Навигация — тонкое
  подчёркивание вместо янтарной пилюли.
- Экран генерации: двухколоночный (промпт+параметры слева, «кадровое окно»
  справа, пустое состояние = приглашение + примеры-чипы).
- Радиусы: единая система rounded-md, пилюли только для чипов.
- Зерно остаётся, но приглушается до opacity 0.3.
- Шапка: ApertureMark наконец используется рядом с логотипом.
- Промпт-бар: не горизонтальный сверху (отходим от индустрии намеренно:
  двухколоночный рабочий стол лучше отвечает «инструменту проявки»).

## Design 2 — «Контактный лист» (галерея как центр)

**Read:** редизайн IA-сдвиг: галерея — главный экран, генерация — панель.
Диски: variance 6, motion 4, density 6.

- Тема: тёмная тёплая, почти монохром; янтарь только на интерактиве.
- Inter Tight доминанта, Unbounded — только логотип и номера кадров.
- Галерея — плотная сетка с подписями-номерами как на контактных листах.
- Генерация — компактная панель поверх/сбоку от галереи (промпт-бар сверху).
- Высокая плотность: компактные карточки, masonry-подход.
- Роутинг: `#/` (лента) и `#/generate` фокус на панели.

## Design 3 — «Проекционный зал» (кинематографический)

**Read:** редизайн-overhaul, драматичный тёмный. Диски: variance 7, motion 7,
density 3.

- Тема: почти чёрный фон (lightness 3-4%), foreground поднят до 94-95%.
- Зерно сокращено до opacity 0.2, только на фонах.
- Изображение — герой: результат занимает до 70% вьюпорта, UI сжимается
  в тонкие боковые панели.
- Промпт-бар горизонтальный сверху (индустриальный стандарт).
- Анимации длиннее: проявка 1.2s, плавные переходы между экранами.
- Риск контролируется: жёсткая дисциплина контраста, минимум текста.

## Design 4 — «Инструмент проявки» (про-утилитарный, Linear-стиль)

**Read:** redesign-overhaul в про-утилитарном ключе для частых пользователей.
Диски: variance 4, motion 3, density 7.

- Тема: тёмная нейтральная (zinc-950 база), моно-акценты, Inter Tight везде,
  Unbounded только в логотипе.
- Компактные контролы (32-36px), command palette (Ctrl+K), keyboard-first.
- Единый примитив загрузки/пустого состояния, тосты для всех действий.
- Админка — полноценный рабочий стол: таблицы с hover-действиями, Radix Select
  вместо нативного, явные disabled с причиной.
- Промпт-бар сверху, результат в ленте снизу (Midjourney-паттерн).

## Design 5 — «Отпечатки на столе» (фотобумага)

**Read:** redesign-overhaul, скевоморфная светло-тёмная гибридная система.
Диски: variance 8, motion 5, density 4.

- Тема: UI-хром тёмный чернильный, каждый результат — «лист фотобумаги»
  (светлая подложка `hsl(40 20% 94%)`, белое поле рамки, лёгкая тень).
- Галерея — отпечатки на тёмном столе (повороты 0.5-1°, при hover выпрямляются).
- Подписи под фото — как карандашные пометки (Inter Tight italic).
- Промпт — «конверт с негативом»: панель ввода стилизована под конверт.
- Риск читаемости на «бумаге» контролируется: текст на бумаге — чернильный,
  контраст AA проверяется на каждом светлом пятне.
