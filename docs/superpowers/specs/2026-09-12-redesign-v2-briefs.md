# gen42 — 5 независимых дизайн-систем, v2

Дата: 2026-09-12. Подход: «пять разных дизайнеров, один бриф».
Каждая система меняет палитру, шрифты, логотип, компоновку и графический
язык. Общие исправления UX (роутинг, disabled при 0 кредитов, стрелки
в лайтбоксе, a11y, примеры-промпты) входят во все варианты по умолчанию
и ниже не повторяются.

## Что чиним (из аудита v1)

- Размытый янтарный акцент: CTA не выделяется.
- Пустой экран генерации до первого результата.
- Нет визуального бренда: ApertureMark не используется, логотип слабее меню.
- Текстовый интерфейс без графики: нет иллюстраций, пустые состояния пустые.
- Три идиомы загрузки, конфликт радиусов, низкая контрастность плейсхолдера.

## Система A — «Бумага» (светлая редакционная)

- **Идея и мотивация.** Генератор как журнал: каждый сеанс — «выпуск»,
  каждая картинка — иллюстрация к нему. Решает пустоту экранов (у выпуска
  всегда есть обложка и содержание) и даёт место графике: большая
  SVG-иллюстрация восхода/диафрагмы в шапке каждого выпуска.
- **Палитра.** Бумага `#f7f3ec`, чернила `#1f1b16`, акцент — терракота
  `#c2502e` (только CTA и активные состояния). Вторичный — оливковый `#6b6a4e`.
- **Типографика.** Заголовки — Cormorant Garamond 600 (обоснованный serif:
  журнальная эстетика), текст — Inter Tight. Крупные номера кадров serif-курсивом.
- **Логотип.** Строчный serif-вордмарк «gen42» с точкой-терракотой вместо
  точки над задачей: «gen42.» Плюс SVG-знак «восход из диафрагмы».
- **Компоновка.** Узкая центральная колонка (редакционный столбец 720px),
  линейная подача: обложка → промпт → галерея-выпуск. Навигация — оглавление.
- **Графика.** Кастомные SVG: восход-диафрагма, разделители-орнаменты,
  иллюстрированные пустые состояния (пустая рамка с карандашным наброском).
- **Движение.** Медленные проявки (1s), плавные перелистывания. Reduced-motion
  respected.
- **Риски.** Светлая тема требует дисциплины контраста серого текста;
  serif кириллица у Cormorant — проверить глифы (есть кириллица, ок).

## Система B — «Пульт» (тёмный инструмент)

- **Идея и мотивация.** Генератор как пульт оператора: скорость и плотность.
  Решает проблему «поэзия вместо инструмента» для частых пользователей:
  всё в один экран, клавиатура первее мыши, лента свежих кадров всегда рядом.
- **Палитра.** Графит `#101216`, панели `#171a20`, текст `#e8eaf0`,
  акцент — лайм `#c6f04a` (только CTA, фокус, активный сегмент). Ошибки — коралл.
- **Типографика.** Space Grotesk (заголовки и UI) + JetBrains Mono
  (цифры, метаданные, kbd-подсказки). Никакого Unbounded.
- **Логотип.** Геометрический знак: квадрат со скруглением и вырезом-«глазом
  камеры», рядом моноширинный «gen42_» с мигающим курсором.
- **Компоновка.** Сайдбар 220px с иконками Tabler + подписями; рабочая зона:
  промпт-бар сверху, сетка свежих кадров 4 колонки. Плотность высокая.
- **Графика.** Иконочная навигация вместо текстовых пилюль, SVG-схема
  «конвейера» (промпт → проявка → кадр) в онбординге, скелетоны как часть
  дизайна, а не заглушка.
- **Движение.** Быстрые переходы 150-250ms, без декоративных анимаций.
- **Риски.** Холодная палитра теряет «тепло» бренда; компенсируется
  характером моноширинных деталей.

## Система C — «Поп-градиент» (тёмный потребительский)

- **Идея и мотивация.** Генератор как игрушка: ярко, дружелюбно, вирально.
  Решает онбординг новичков: игривые пустые состояния и стикеры снижают страх
  чистого листа; результат хочется шарить.
- **Палитра.** Чернила `#0d0b1e`, акцент-градиент индиго `#6c5cff` →
  фуксия `#ff5ca8`, солнечный `#ffd54a` для звёзд/стикеров.
- **Типографика.** Bricolage Grotesque (характерный гротеск с «прыгающими»
  формами) для заголовков, Inter Tight для текста.
- **Логотип.** Пузырьковый вордмарк «gen42» с градиентной заливкой и
  SVG-звёздочкой-искрой вместо точки.
- **Компоновка.** Центрированный столбец, крупные круглые карточки
  (radius 20-24), промпт-бар-«пилюля» с градиентной кнопкой, лента кадров
  masonry с hover-подъёмом.
- **Графика.** SVG-стикеры (звёзды, вспышки, спирали), mesh-градиентный фон,
  иллюстрированные пустые состояния («холст ждёт»).
- **Движение.** Пружинные hover, конфетти-проявка результата. Строгий
  reduced-motion fallback (статика).
- **Риски.** Легко скатиться в «AI-slop»; держится за счёт одного градиента
  и строгой сетки.

## Система D — «Брутализм» (светлый конструктивистский)

- **Идея и мотивация.** Генератор как плакат: честная сетка, чёрные рамки,
  никаких полутонов. Решает размытость иерархии радикально: важность =
  толщина рамки и кегль, а не оттенок серого.
- **Палитра.** Белый `#ffffff`, чёрный `#111111`, один сигнальный акцент —
  электрик `#2b4eff` (только CTA и активные рамки). Серый только для
  второстепенного текста `#6b6b6b`.
- **Типографика.** Archivo Black (заголовки, uppercase) + Space Mono
  (метки, кнопки, цифры). Жёсткая иерархия кеглями.
- **Логотип.** Плашка: чёрный прямоугольник с белым «GEN42» моноширинным,
  рядом SVG-звезда-взрыв.
- **Компоновка.** 12-колоночная сетка с видимыми границами, жёсткие панели
  с hard-shadow (4px 4px 0 #111), маркированные секции «01 / ПРОМТ».
- **Графика.** Плакатные SVG: звёзды, стрелки, штриховки; пустые состояния —
  контурные рамки с диагональной штриховкой и подписью «ТУТ БУДЕТ КАДР».
- **Движение.** Минимум: мгновенные смены, marquee-бегущая строка статуса
  (одна на страницу). Reduced-motion: статика.
- **Риски.** Агрессивность утомляет; компенсируется щедрым воздухом между
  панелями.

## Система E — «Закат» (тёплый дружелюбный тёмный)

- **Идея и мотивация.** Генератор как тёплый вечер: уютный, округлый,
  человечный. Сохраняет теплоту исходного бренда, но меняет всё остальное:
  коралл вместо янтаря, пилюли вместо прямоугольников, иллюстрации вместо
  текста-заглушек.
- **Палитра.** Какао `#1a1210`, панели `#241915`, текст `#f5e9e2`,
  акцент — коралл `#ff7a59` (CTA, фокус), вторичный — персик `#ffb59e`.
- **Типографика.** Sora (мягкий геометрический гротеск) для заголовков,
  Inter Tight для текста. Круглые формы шрифта рифмуются с пилюлями.
- **Логотип.** Круглый знак «солнце-кадр»: коралловый круг с белым
  прямоугольником кадра внутри; вордмарк «gen42» строчными Sora.
- **Компоновка.** Мягкие пилюли-навигация, промпт-карточка с radius 24,
  галерея крупными круглыми карточками, баланс — «кошелёк» с иконкой.
- **Графика.** SVG-иллюстрации заката, волн, кадров-полароидов;
  пустые состояния — иллюстрация «пустая рамка на закате».
- **Движение.** Плавные 400ms, «дышащий» glow вокруг активного кадра.
- **Риски.** Коралл на тёмном требует проверки контраста белого текста
  (использовать тёмный текст на коралловых кнопках).
