# gen42 — Система C «Поп-градиент» (v2)

Дата: 2026-09-12. Ветка: `redesign-c`. Статус: эталон направления C.

## 1. Исследование (референсы)

Изучены: игривые потребительские AI-инструменты (Playyy — холст-центричный генератор,
Variant/Makeswift — тёмный фон + стикеры-варианты как контент, GenieStudio-лендинг —
пастельные стикеры поверх спокойного холста) и разборы тёмных лендингов
(dark-aurora: максимум 1–2 источника свечения; deslopify/slop-энциклопедия:
градиент синь→фиолет стал маркером «AI-slop», лечится дисциплиной).

Выводы, зафиксированные как правила системы C:

1. **Цвет несёт иллюстрация, а не хром.** У GenieStudio весь хром спокойный, энергия —
   в стикерах и тинтах. У нас наоборот по теме (тёмный холст), но принцип тот же:
   градиент — ОДИН и только там, где действие или бренд (CTA, логотип, активный пилюльный
   сегмент). Панели, таблицы, скелетоны — плоские.
2. **Строгая сетка держит «игрушку» от slop.** Variant выглядит живо за счёт контента
   (сами стикеры), а не декора: сетка ровная, карточки одинакового ритма. Поэтому:
   центрированный столбец единой ширины, ровный gap, masonry только в галерее.
3. **Градиент не льём по фону.** Aurora-рецепт: 1–2 мягких mesh-источника с маской
   и шумом 3–5%, ни в коем случае не `bg-gradient-to-r` на всю страницу и не
   `bg-clip-text` на заголовках (маркер slop №13–14). Текст заголовков — сплошной
   светлый, градиент — только заливка кнопки/логотипа.
4. **Пустое состояние — тоже контент.** У Playyy и Variant продукт показывают, а не
   объясняют. Пустые экраны Generate/Gallery получают иллюстрацию («холст ждёт»),
   а не текстовую заглушку.
5. **Один скелетон вместо трёх идиом загрузки.** Deslopify-правило: спиннеры в контенте —
   slop; скелетон повторяет геометрию результата (квадрат 1:1 + строки).

## 3. Токены

```css
--color-background: #0d0b1e;   /* чернила */
--color-card:       #16132e;   /* приподнятая панель */
--color-foreground: #f2efff;   /* почти белый с фиолетовым подтоном */
--color-muted-foreground: #b3aedd; /* светлая лаванда: плейсхолдер AA на #0d0b1e */
--color-border:     #2b2652;
--pop-indigo: #6c5cff; --pop-fuchsia: #ff5ca8; --pop-sun: #ffd54a;
--pop-gradient: linear-gradient(120deg, #6c5cff, #ff5ca8); /* ЕДИНСТВЕННЫЙ градиент */
```

Градиент применяется только: primary-CTA (`buttonVariants.default`), логотип-вордмарк,
активный сегмент навигации, тонкая верхняя кромка результата. Всё остальное — плоское.
Солнечный `#ffd54a` — только звёзды/стикеры/seed-бейдж, никогда текст на нём мелкий.

Радиусы: карточки `rounded-[22px]`, пилюли/кнопки `rounded-full`, поля `rounded-2xl`.
Тени: мягкие фиолетовые `0 18px 50px -18px rgb(108 92 255 / .45)` на CTA и hover карточек.

## 4. Шрифты

- Заголовки/вордмарк: **Bricolage Grotesque** 600–800, tight tracking. Мотивация: характерный
  «прыгающий» гротеск = игрушечность без комиксанса; кириллица есть.
- Текст/UI: **Inter Tight** 400–600 (наследие проекта, менять не надо).
- Цифры/seed/даты: `tabular-nums`, моно не вводим (моно — язык системы B «Пульт»).

## 5. Логотип

`PopLogo` (graphics.tsx): пузырьковый вордмарк «gen42» (Bricolage 800, заливка
`--pop-gradient` через `background-clip`) + SVG-искра `SparkStar` (четырёхугольная звезда,
заливка `#ffd54a`) вместо точки/рядом с «42». Favicon — та же искра на `#0d0b1e`.
Мотивация: один градиент = бренд узнаётся даже в фавиконе; звезда повторяется в стикерах
и пустых состояниях (визуальная рифма вместо разрозненного декора).

## 6. Компоновка

- Центрированный столбец: `max-w-3xl` (главный экран), `max-w-5xl` (админка),
  Auth — две колонки → на мобильных одна, карточка формы `rounded-[24px]`.
- Шапка (ред. 2): липкая; только логотип, баланс-пилюля (иконка + число)
  и кнопка аккаунта-иконкой с меню. Вкладок нет.
- Главный экран: промпт-карточка (`rounded-[24px]`, лейбл + поле без
  плейсхолдера + чипы примеров), графическая круглая кнопка генерации
  + пиктограмма «монета → кадр», результат — крупная круглая карточка,
  ниже — лента «Недавние» (сетка последних кадров + лайтбокс).
- Контент живёт на странице, не в «окошке»: одна карточка на смысловой блок, воздух
  между блоками 40–64px.

## 7. Графический язык

- `MeshBackground`: два мягких radial-источника (индиго сверху-слева, фуксия снизу-справа,
  opacity ~0.16/0.12) + SVG-шум 4% + маска к краям. Мотивация: глубина без «обоев»,
  по aurora-рецепту; зерно плёнки удалено.
- Стикеры `SparkStar` / `StickerBurst` / `StickerSpiral`: контурные или солнечные,
  расставлены скупо (Auth-фон, рядом с результатом, пустые состояния). Правило: не больше
  двух стикеров на экран — анти-slop предохранитель.
- Пустые состояния — иллюстрации: `EmptyCanvasArt` («холст ждёт»: рамка-кадр со звёздами
  и спиралью), `EmptyGalleryArt` (стопка кадров + вспышка). Рядом — чипы примеров,
  клик подставляет промпт.
- Иконки только `@tabler/icons-react`; своя SVG-графика только в `graphics.tsx`.

## 8. Движение

- Пружина: `cubic-bezier(.34,1.56,.64,1)` 250–450ms на hover-подъём, появление результата
  (`pop-in`: scale .96→1 + translateY 10px→0), стикеры — медленный float 6s.
- Скелетон `PopSkeleton`: shimmer-волна по плоской панели (геометрия = будущий кадр).
- `prefers-reduced-motion: reduce` — строгая статика: все анимации `none`, shimmer
  заменяется плоской панелью, mesh-фон статичен. Мотивация: игривость не должна укачивать;
  fallback — не «помедленнее», а «никак».

## 9. Доступность и UX-инварианты (общие для v2, реализованы здесь)

Хеш-роутинг `#/`, `#/admin` (раздела «Галерея» нет, см. R4); disabled CTA
при балансе 0; лайтбокс prev/next (кнопки + `ArrowLeft/Right` + Escape);
`focus-visible` везде; чипы примеров; единый скелетон; `role="alert"` у всех
ошибок.

## 10. Правила экономии текста и графики (ред. 2, по ревью)

- **R1. Только функциональный текст.** Разрешены: заголовки экранов
  («Вход», «Регистрация»), лейблы полей, тексты ошибок, короткие подписи
  действий («Скачать», «Закрыть», «Выйти» в меню). Запрещены объясняющие
  и маркетинговые строки («Придумывайте картинки словами…», «Начните
  с примера…», «С возвращением…», «Один кредит — одно изображение»,
  «это займёт несколько секунд» и любые их аналоги).
- **R2. Плейсхолдеры запрещены везде.** У каждого поля — видимый `Label`
  сверху, атрибут `placeholder` не используется нигде.
- **R3. Вход — «Продолжить» с иконкой.** Заголовок строго «Вход» /
  «Регистрация». Кнопка — «Продолжить» + `IconArrowRight`; слово «Войти»
  не используется.
- **R4. Один экран, без вкладок и без Галереи.** Навигационных табов нет,
  отдельного раздела «Галерея» и роута `#/gallery` нет (старая ссылка
  ведёт на главный экран). История — лента «Недавние» на главном экране:
  сетка последних кадров, клик открывает лайтбокс.
- **R5. Шапка-минимум.** Только логотип, баланс (иконка + число) и кнопка
  аккаунта-иконкой (`IconUserCircle`) с выпадающим меню: email (инфо),
  ссылка админки (только админу), выход. Email и «Выйти» текстом в шапке
  запрещены.
- **R6. Кредит — графически.** Правило «1 кредит = 1 изображение» выражается
  только пиктограммой (монета → кадр) с `aria-label`, без строки текста.
  Кнопка генерации — графическая: круглая градиентная кнопка-иконка
  (`IconSparkles`) с `aria-label="Сгенерировать"`, без текстовой подписи.
  Состояние «нет кредитов» — та же кнопка в disabled + баланс-пилюля
  в цвете ошибки; объясняющего текста нет.
- **R7. Счётчики символов запрещены везде.**
- **R8. Графика вместо слов.** Пустые состояния, загрузки и статусы —
  иллюстрациями из `graphics.tsx`, а не абзацами. Текст рядом с иллюстрацией
  допустим, только если без него действие непонятно (ошибка, disabled-причина
  для скринридера через `aria-label`, а не видимый текст).

## 11. Контроль качества вёрстки (чеклист каждого ревью)

- **Q1. Нет нестилизованных нативных элементов.** `select`, `checkbox`,
  `radio` — только shadcn/Radix-стилизованные (`ui/select.tsx` и др.).
  Нативный контрол без скина — брак.
- **Q2. Одна граница у поля ввода.** Либо рамка у самого поля, либо рамка
  у контейнера с `focus-within` + поле с `border-0`. Двойная рамка
  (контейнер + поле одновременно) — брак.
- **Q3. Нет обрезанного текста.** `truncate`/`line-clamp`/`overflow-hidden`
  без `title` — брак; длинные email, промпты, имена файлов переносятся
  или урезаются с тултипом. Проверка на 360px.
- **Q4. Нет ошибок вёрстки.** Нет горизонтального скролла, наложений,
  «прыгающей» шапки при загрузке баланса (скелетон вместо пустоты),
  разъехавшихся отступов между брейкпоинтами.
